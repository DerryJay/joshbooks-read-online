# JoshBooks Library

Build a small-scale, modern, responsive online library website demo called JoshBooks.



Project goal



JoshBooks is a simple digital library where users can browse books, search for books, view book information, and read available books directly on the website.



Important scope



This is ONLY a frontend demo for now.



Do NOT add:



- Login or registration

- Authentication

- User accounts

- Admin dashboard

- Borrow/return functionality

- Payment features

- Database

- User profiles



Use sample/public-domain books or clearly labeled demo books.



Pages



1. Home Page

Create a professional homepage for JoshBooks with:



- JoshBooks logo/name

- Navigation bar:

  - Home

  - Books

  - About

- Hero section with:

  "Welcome to JoshBooks"

- Subtitle:

  "Discover, explore, and read books online."

- "Explore Books" button

- Featured books section

- Short About JoshBooks section

- Footer



2. Books Page

Create a searchable digital book catalogue.



Each book card should display:



- Book cover

- Title

- Author

- Category

- Short description

- "View Details" button

- "Read Book" button



Add:



- Search bar

- Category filter

- Responsive grid layout



The search should work instantly as the user types.



3. Book Details Page

When a user selects a book, display:



- Large book cover

- Title

- Author

- Category

- Description

- Publication information

- "Read Book" button

- "Back to Books" button



4. Online Reader

Create a clean reading interface where users can read a selected book directly inside JoshBooks.



For the demo, use local PDF files or sample/public-domain books.



Include:



- Book title

- PDF/document viewer

- Page navigation where supported

- Zoom controls

- Page number

- Full-screen option where supported

- "Back to Book" button



Sample content



Add at least 6 sample/public-domain books to demonstrate the catalogue.



Each book should have:



- Title

- Author

- Category

- Description

- Cover image

- Readable PDF/content



Do not use copyrighted books without permission.



Design



Give JoshBooks a:



- Modern

- Clean

- Professional

- Academic/library-inspired appearance

- Responsive mobile design

- Attractive book cards

- Smooth hover effects

- Clear call-to-action buttons

- Good typography

- Consistent spacing



Create a simple, recognizable JoshBooks logo/wordmark.



Use a polished color palette appropriate for a digital library.



Technical requirements



- Use React and modern frontend practices.

- Use reusable components.

- Store the book catalogue in local data for now.

- No backend or database.

- No authentication.

- Make search and category filtering functional.

- Make all navigation buttons functional.

- Make the Read Book buttons open the correct book in the reader.

- Ensure the website works well on both desktop and mobile.

- Keep the code organized so authentication and a database can be added later.



Future development



Structure the project so that we can eventually add:



- User registration/login

- Database

- Admin dashboard

- Book uploading and management

- Borrowing/returning

- Reading history

- Favorites/bookmarks

- User profiles



For this version, focus on making JoshBooks a polished, functional frontend demo that can be tested immediately.vorites/bookmarks
